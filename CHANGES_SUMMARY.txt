REGISTRY: GitHub Container Registry (GHCR) ONLY

  - Free unlimited storage
  - No rate limits
  - Integrated with GitHub
  - No Docker Hub dependency

PLATFORMS SUPPORTED:
  - linux/amd64 (x86_64)
  - linux/arm64 (ARM 64-bit)

IMAGE TAGS:
  - latest (stable release)
  - develop (development builds)
  - v1.2.3 (semantic versions)

================================================================================
AUTOMATION WORKFLOW
================================================================================

1. PULL REQUEST → Any Branch
   - Runs tests (lint, typecheck, build)
   - No images published

2. PUSH TO develop
   - Runs tests
   - Builds multi-platform images
   - Publishes to: ghcr.io/mash2k3/agregarr:develop

3. PUSH TO latest
   - Runs semantic-release
   - Analyzes commit messages
   - Determines version number
   - Creates GitHub release
   - Builds and publishes versioned images to GHCR

================================================================================
REQUIRED SETUP (FOR MAINTAINERS)
================================================================================

GITHUB SECRETS:
  Repository Settings → Secrets and variables → Actions

  1. GITHUB_TOKEN
     ✅ Automatically provided by GitHub (no action needed)

REPOSITORY SETTINGS:
  1. Go to: Settings → Actions → General → Workflow permissions
     Set to: "Read and write permissions"
     Enable: "Allow GitHub Actions to create and approve pull requests"

  2. Go to: Settings → Features
     Ensure: "Packages" is enabled

================================================================================
USAGE EXAMPLE
================================================================================

DOCKER COMPOSE:
  services:
    agregarr:
      image: ghcr.io/mash2k3/agregarr:latest
      container_name: agregarr
      volumes:
        - /path/to/config:/app/config
      ports:
        - 7171:7171
      restart: unless-stopped

DOCKER RUN:
  docker run -d \
    --name agregarr \
    -p 7171:7171 \
    -v /path/to/config:/app/config \
    --restart unless-stopped \
    ghcr.io/mash2k3/agregarr:latest
